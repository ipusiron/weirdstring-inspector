🕵️ WeirdString Inspector

怪しい文字列を入力すると、異常なUnicode文字（ゼロ幅スペース、Zalgo、そっくり文字など）を検出し、重大度と理由を表示します。

入力の読み方

UTF-8ファイルから入力

1ファイル、1MiB・100,000コードポイントまで。BOMと改行を保持します。内容は外部へ送信しません。

        📖 WeirdString Inspectorヘルプ
        
          
        
        
        
        
          
        🔍 このツールについて
        
          
        文字列に紛れた不審なUnicode文字を検出するツールです。判定は文字の種類と前後関係に基づくもので、攻撃の有無を確定するものではありません。
        
          
        🎯 使い方
        
          
          
            
        1. 入力欄に文字列を貼り付ける。
          2. 
            
        2. 判定と、種類ごとの件数を見る。
          3. 
            
        3. 「見た目」と「中身」を比べる。双方向制御があっても「中身」は実際の並び順である。
          4. 
            
        4. 中身のラベルをクリック、またはTabとEnterで選び、理由やコードポイントを読む。
          5. 
            
        5. 隠された内容、語の判定、比較用の文字列、正規化、文字の表で詳細を確認する。
          6. 
          
        
          
        重大度の3段階
        
          
          
            
        • 危険：見た目と中身が食い違う文字、または隠された内容
          • 
            
        • 注意：気づきにくい文字
          • 
            
        • 情報：特殊だが普通の使い方の範囲の文字（例：👨‍💻のZWJ）
          • 
          
        
          
        検出する文字の種類
        
          
        
            
        
              
        キー種類対象重大度
        
              
              
        tagタグ文字U+E0000〜E007F。表示されず、ASCIIの文字に1対1で対応するので文を隠せる危険（絵文字の旗を作るものは情報）
        
              
        bidi双方向制御埋め込み・上書き・分離（U+202A〜202E、U+2066〜2069）と、LRM・RLM・ALM前者は危険、後者は注意
        
              
        variation異体字セレクターU+FE00〜FE0F、U+E0100〜E01EFなど1個なら情報、2個以上の連続は危険
        
              
        invisible不可視文字ZWSP・ZWNJ・ZWJ・WJ・BOM・SHY・CGJ・ハングルフィラーなど注意。ASCIIの英数字の間なら危険。絵文字のZWJ・先頭のBOMなどは情報
        
              
        control制御文字C0（TAB・LF・CRLFを除く）・DEL・C1。単独のCRを含む注意
        
              
        whitespace特殊な空白U+0020以外の空白（NBSP・全角スペース・ヘアスペースなど）、U+2028・U+2029、TAB注意（TABは情報）
        
              
        private私用領域・非文字私用領域・非文字・対になっていないサロゲート注意
        
              
        zalgo積み重ねた結合記号結合記号の5個以上の連続、または同じ結合記号の連続（UTS #39）注意
        
              
        combining結合記号上記以外の結合記号（分解形の文など）情報
        
              
        compat互換文字NFKCでASCIIの英数字になる文字（数学用英字・丸数字・全角英数など）注意（全角英数は情報）
        
              
        lookalikeそっくり文字confusables.txtでASCIIに見える文字混在した語の中・全体がASCIIに見える語・URLの区切りに見える記号は危険、ASCIIの語の中は注意、ほかは情報
        
              
        mixedスクリプトの混在1つの語の中の、ほかと違うスクリプトの文字危険
        
                      
            
        
          
        
          
        普通の日本語や句読点、LF・CRLFは検出しません。ASCIIどうしの紛らわしさ（1・l・I、0・O、rn・m）は対象外です。
        
          
        入力の読み方
        
          
        通常は「そのまま読む」を選びます。「エスケープ表記を解釈する」では、\u{202E}や\rなどを文字に戻して検査します。
        
          
        入力欄はCRをLFに変えるため、CRを含むサンプルやURLはエスケープ表記で読み込みます。CRがある結果は入力欄へ戻せません。
        
          
        ほかのツールからの連携
        
          
        ?text=と#text=で文字列を渡せます。両方ある場合は#text=を優先します。file://でも使えます。
        
          
        ?text=の内容はサーバーへ送られ、ログに残る可能性があります。#text=の内容はサーバーへ送られません。機密情報の扱いに注意してください。
        
          
        出所と判定の範囲
        
          
        UTS #39、confusables.txt（Version 18.0.0）、UTS #46に基づきます。ASCIIに見える2,249件、見え方423種類の表を同梱しています。
        
          
        ブラウザーが持つUnicodeの版によって、スクリプトや文字の種類の判定に差が出ることがあります。完全なUnicode名の辞書や双方向表示アルゴリズムは実装していません。
        
          
        ⌨️ キーボード操作
        
          
        サンプルのタブは←→とHome・Endで選べます。Tabでボタンや文字のラベルに移動し、Enterで操作します。Escでヘルプを閉じます。
        
          
        🌓 ダークモード
        
          
        右上の月・太陽ボタンで切り替えます。保存した設定がなければシステム設定に従います。保存を拒否する環境でも使用できます。
